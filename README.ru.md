# Ядро теста SDRAM для Karabas Go / Mini / Mini G

[English version](README.md)

Тест SDRAM плат семейства Karabas Go (Xilinx Spartan-6 XC6SLX25, микросхема SDRAM MT48LC16M16A2-75,
32 МБ). Ядро по кругу записывает во всю микросхему псевдослучайные данные, читает их обратно,
сравнивает и показывает результат на экране. Один файл ядра `sdrtest.kg` для всех трёх плат. В
загрузочном меню ядро скрыто (`"visible": false`), его загружают по имени (`sdrtest`).

Исходный проект: zebest, sorgelig, DDp и lvd (MemTest для MiSTer). Клавиши смены частоты сделаны как
в этом MemTest.

## Экран

- Верхняя строка (жёлтая): сколько минут идёт тест и частота SDRAM в МГц.
- Средняя строка (зелёная): число проходов, шестнадцатеричное. Проход — одна запись и одно чтение
  всей микросхемы.
- Нижняя строка (красная): число ошибок, шестнадцатеричное. Любое значение кроме 0 значит, что на
  этой частоте память сбоит.
- Метка, которая сдвигается раз в секунду, показывает режим auto (ниже).

## Клавиши

| Клавиша | Что делает |
|---|---|
| ↑ / ↓ | Следующая / предыдущая частота SDRAM: 100, 110, 120, 130, 140, 150, 160, 166 МГц |
| Enter | Режим auto вкл. / выкл.: после каждой минуты без ошибок частота поднимается на шаг; ошибка опускает её на шаг и выключает auto |
| Reset в OSD | Начать тест заново |
| Global Reset в OSD | Вернуться в загрузочное ядро |

При смене частоты тест начинается заново: проходы, ошибки и время обнуляются.

Микросхема рассчитана на 133 МГц: ошибки на 150 МГц и выше — это нормально, они показывают запас
конкретной платы, а не неисправность. Если ошибки есть уже на 100 МГц, с платой что-то не так
(микросхема, пайка, питание).

## Платы

- Все три платы: связь с МК версии 2 (`kg_mcu2`, прошивка 26111315 или новее), OSD из
  [karabas-go-modules](https://github.com/andykarpov/karabas-go-modules), клавиши частоты. Частоту
  тестера даёт DCM_CLKGEN ПЛИС, который перепрограммируется на ходу (CLKFX = 50 МГц × M / D); на SDRAM
  она идёт инвертированной, как раньше от PLL. Mini G и Mini: HDMI; Go: VGA.
- Сборки: Mini G 26111321 (проверена на плате), Mini и Go 26111327 (на плате ещё не запускались).

## Сборка

ISE 14.7: `cd src && make minig` (или `go`, `mini`, или `make` для всех трёх). Результат: битстримы
`karabas_<плата>_top.bin` и `sdrtest.kg` (его собирает `make_core.py` из `core.json`). Общие модули —
подмодуль `modules` (karabas-go-modules): `git submodule update --init`.
